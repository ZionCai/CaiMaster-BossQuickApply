# 菜大师BOSS海投助手

> BOSS直聘高效投递工具：AI 智能招呼语 + 半自动投递 + 批量海投 + 简历导入
>
> **当前版本：v2.1.0** ｜ [更新日志](CHANGELOG.md) ｜ [Bug 修复报告](BUGFIX-REPORT.md)

## 功能

- 🤖 **AI 智能招呼语** — 点击职位卡片，AI 结合岗位要求 + 你的简历生成个性化招呼语，可编辑、可重新生成
- 📝 **招呼语预览** — 生成后直接改，确认无误再发送
- ⚙ **API 配置** — 兼容 OpenAI 协议（DeepSeek / 通义 / OpenAI / 各类中转站），带「测试连接」
- 📤 **简历导入** — 支持 `.docx` / `.pdf` / `.txt` / `.md`，自动识别并填入简历框
- 🚀 **一键投递** — 半自动模式：确认招呼语后投递当前职位
- ▶ **批量海投** — 全自动模式：按筛选条件批量沟通
- 📊 **运行统计** — 面板底部实时显示已沟通 / 已发简历 / 已跳过 / 失败

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展（Chrome / Edge 均可）
2. 打开 Tampermonkey → **添加新脚本**
3. 粘贴 `boss-quick-apply.user.js` 全部内容 → `Ctrl + S` 保存
4. 打开 BOSS 直聘职位列表页：**https://www.zhipin.com/web/geek/jobs**
5. 页面右侧出现紫色面板即安装成功（若未出现，刷新一次页面）

## 使用

### 方式一：AI 半自动（推荐）

1. 设置 ⚙ → **AI 设置**：填 API 地址 / API Key / 模型 → 点「测试连接」确认可用
2. 填写**个人简历**（可点「导入简历」上传 Word/PDF 自动识别）
3. 按需补充「自我介绍」与「招呼语模板」
4. 回到职位页，确认 🤖 **AI 智能招呼语**开关为开启
5. **点击任意职位卡片** → 1~2 秒后预览区出现招呼语
6. 编辑确认后点 **🚀 一键投递**

### 方式二：全自动批量海投

1. 关闭 🤖 AI 开关
2. 填写「职位名包含」「工作地包含」筛选条件
3. 点 **▶ 启动海投**，脚本会滚动收集岗位并逐个沟通

> 为了账号安全，建议在设置中把「投递间隔」保持在 2500ms 以上、「单次投递上限」控制在 50 以内。

## 常见问题

| 现象 | 处理 |
|---|---|
| 面板不出现 | 确认地址是职位列表页；刚安装脚本请刷新页面（Ctrl + F5） |
| 配置刷新后消失 | v2.1.0 已修复 |
| 只扫描不投递 | v2.1.0 已修复；另外请确认已在 BOSS 设置页开启「打招呼语」 |
| AI 招呼语生成失败 | 设置 → AI 设置 → 点「测试连接」，按提示排查 Key / 余额 / 地址 |
| Word 简历导入没反应 | v2.1.0 已修复（旧版无法解析 .docx） |
| 想恢复面板 | 点左下角圆形图标，或按 F5 刷新 |
