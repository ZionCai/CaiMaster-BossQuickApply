# 菜大师BOSS海投助手

BOSS直聘高效投递工具，支持AI智能招呼语、半自动投递、简历导入。

## 功能

- 🤖 **AI智能招呼语** - 点击职位卡片自动生成个性化招呼语
- 📝 **招呼语预览** - 可编辑，重新生成
- ⚙ **API配置** - 支持DeepSeek等兼容OpenAI的API
- 📤 **简历导入** - 支持Word/PDF/TXT格式
- 🚀 **一键投递** - 半自动模式逐个投递
- ▶ **批量海投** - 全自动模式批量沟通

## 安装

1. 安装 Tampermonkey 浏览器扩展
2. 新建脚本，粘贴 `boss-quick-apply.user.js` 全部内容
3. 保存后在 BOSS直聘职位列表页使用

## 使用

1. 打开设置 → 配置API Key（DeepSeek等）
2. 填写个人简历和招呼语模板
3. 开启AI开关 → 点击职位卡片自动生成招呼语
4. 编辑确认后点击一键投递
